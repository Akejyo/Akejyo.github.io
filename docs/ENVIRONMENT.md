# Environmental storytelling — maintenance notes

These notes are for the site owner. They are not served as public routes or explained in the interface.

- **404:** an original SVG snow field, distant conifers, sparse drifting snow and six static barefoot impressions. The walking cadence omits a left step near the center; its continuation is much farther ahead. The response retains HTTP 404 and a normal Return link.
- **`/void`:** HTTP 200, `noindex`, no navigation entry. One flower, a darkened existing landscape, faint static footprints, and the requested two-line text. Browser Back works normally.
- **Flower:** native button, accessible name and keyboard focus. Five activations spaced 450–4,000 ms apart trigger Level I. First: no extra response. Second: existing center response (0.48 opacity). Third: inner rings move approximately 3 screen pixels. Fourth: brief crimson center at 0.88 opacity and the same ring offset. Responses have 600ms entry transitions and 1.2-second active states; subsequent responses replace earlier ones. Fifth: Level I. Rapid tapping or a long pause restarts the sequence. Level I lasts ten seconds with a sixty-second cooldown afterward. There is no message, score, sound, or explanatory label. Normal flower color/ring transitions and restoration use 1,000ms, so short deliberate feedback can resolve visibly.
- **Level I:** ambient snow/fog slows to a stop over 700ms; automatic Collapse exposure pauses. Only decorative textiles, fine lines, flower colors, and background layers change. Environmental displacement is 4px in each axis, suppressed for reduced motion; SVG lines shift 4 screen pixels using their rendered scale. Existing textile masks and incompatible repeat remain, with repeat echo at 0.7 opacity. Flower center/inner/outer opacities are 0.9/0.7/0.68. Entry transitions take 700ms; after the unchanged ten-second active interval, colors, offsets and ambient playback restore over 1,000ms. Binary SVG masks restore immediately. Hidden tabs and page departures clear the active state and pause ambient work. No content is transformed.
- **Archive:** after the third page visit, a four-percent chance replaces only the decorative count with `?`. The correct count remains available to assistive technology. Every dated record and link remains unchanged.
- **Persona Cresson response:** the canonical composition is presented above the biography. The flower in the artwork is a native, keyboard-accessible button registered to the same `FlowerSequence` as the abstract About emblem. Both receive the same transient response classes and global Level I state. There is no visit eligibility or dwell timer for the Persona. See the Persona maintenance section below.
- **Transitions:** native cross-document View Transitions provide a 250ms fade where supported. Rare eligible navigations keep a 120px environmental fragment for another 450ms before its 250ms fade (700ms total). It is the previous document's named `environment-memory` snapshot: only landscape/snow pixels, never article text or UI. Its normal opacity remains 0.025, raised to 0.5 only on the departing page during rare handoff, with a 12px downward spatial offset. Void uses a darker fragment of the same landscape. The unchanged rarity is 3.5% from the third page visit onward. A short-lived session marker reaches the destination before paint, is consumed once and expires after ten seconds; arrival styling clears after 900ms. Links are never intercepted or delayed. Other browsers use ordinary navigation. Reduced motion disables transition animations.
- **Persistence:** one capped local page-visit counter, and an optional one-navigation session marker. No analytics, cookies, network tracking, audio, or external dependencies. Storage denial is harmless.

## Ambient environment

Home hero, 404 and `/void` mount the same `SnowAtmosphere()` decoration. There are 24 flakes total: background 12 (2px, opacity 0.25, 30–36s), midground 9 (3px, opacity 0.52, 18–24s), foreground only 3 (6px, opacity 0.38, 1px blur, 10–14s). Negative phase offsets make drift visible immediately. Flakes travel 870px per cycle with alternating 18–46px horizontal drift; masks keep the reading areas clear. A very faint fog layer drifts 18px horizontally / 5px vertically over 36 seconds, alternating direction. Landscapes have a static 1.015 overscan to prevent exposed edges during Level I, not scroll-linked parallax.

At widths up to 760px, 12 flakes remain (6 background, 5 middle, 1 foreground). Articles and other non-atmospheric pages have no snow layer. Reduced motion replaces moving layers with a 0.03-opacity static snow texture and disables flower/transition animation. Without JavaScript no ambient animation starts. Hidden tabs pause playback. CSS supplies motion; `environment.js` changes playback rate only during short 700/1,000ms state ramps (50ms steps), with no perpetual JavaScript frame loop or added dependency.

Implementation: `story-art.js` contains original geometry, snow layers and the flower button; `story.css` isolates visual states; `story.js` manages sequence/lifecycle behavior and installs `environment.js`; `story-arrival.js` transfers the transient navigation marker. `CollapseController` pauses while Level I is active. Existing article CSS and MDX are unchanged. See [the complete before/after report](REBALANCE.md).

Run `npm run check` and `npm test`. Tests cover deliberate versus rapid interactions, ten-second restoration, cooldown, hidden-page cancellation, storage failures, guarded archive rarity, hidden-route isolation, real 404 responses, and reliable article content.

## Persona composition and maintenance

Canonical source: `E:\imgs\ai-generate\persona.png` (5504 x 3072), supplied by the site owner. `scripts/prepare-persona.ps1 -Source <path>` creates JPEG derivatives at quality 92: full composition 960/1600/2400 pixels wide, and centered 4:5 crops at 640/960 pixels wide. The source is not modified. Desktop uses contain, original aspect ratio and a 70vh ceiling; the image sits above the unchanged biography. Mobile (up to 600px) uses art-directed picture sources preserving face, framing hair, hands, flower and table edge. Far peripheral darkness and outer candles are cropped. Width/height and aspect ratio reserve layout space.

`persona-art.js` registers the flower at 50.3% / 69% of the full composition (50.67% / 69% in the mobile crop). The invisible native button covers the petals and has a visible keyboard-only focus outline. An independently filtered copy of the same responsive image is clipped to the flower; soft SVG illumination aligns to the two nearby candles. No face, eye, hair or body geometry is animated. Candle illumination has one restrained nine-second variation on hover, never a perpetual character animation.

Five paced activations use the unchanged 450-4,000ms interval: first quiet; second a faint crimson center; third a slight broken-ring displacement; fourth stronger flower saturation and weaker candle illumination; fifth the existing ten-second Level I. The Persona and abstract flower share the sequence even when alternating targets. Responses last 1.2 seconds and replace one another; cooldown remains sixty seconds after Level I. Nothing explains the sequence publicly.

Level I applies saturation 0.92 and brightness 0.96 to the base artwork, while the clipped flower layer uses saturation 1.18 / brightness 1.08 at 0.65 opacity. Candle illumination weakens. Restoration uses the same controller cleanup on timeout, page departure and hidden tabs. Reduced motion removes transitions, candle fluctuation and ring movement, retaining static color differences.

The previous red-eye/iris overlay, visit eligibility, dwell timers, synchronization, QA actions and tests were removed. Development QA now provides Persona activation, flower response, shared Level I, reset, hit-area highlighting and overlay alignment. Guides live exclusively in the development-only stylesheet; closing QA clears them. The old `persona.webp` is retained only as an unreferenced asset, not mounted or requested.
